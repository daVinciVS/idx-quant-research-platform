# IDX Quant Research Platform

A Python-based research and decision-support platform for Indonesian equities.

The project supports:

- Market-data ingestion and validation
- Daily-candle integrity checks for the Jakarta market
- Technical screening and trend-template analysis
- Wyckoff-style market-structure classification
- ATR-based trade planning and risk levels
- Broker summary and foreign-flow inputs
- Walk-forward backtesting
- Excel and PDF research-report generation

## Disclaimer

This project is for research, education, and software-engineering demonstration purposes only. It does not provide investment advice, trading recommendations, or guaranteed forecasts. Historical performance does not guarantee future results.
